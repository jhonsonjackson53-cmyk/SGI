# Abrir Obsidian para SGI

No abras esta carpeta raiz `SGI` como boveda de Obsidian.

La boveda correcta es:

```text
C:\Users\EG\Documents\Codex\2026-06-28\github-plugin-github-openai-curated-remote-2\SGI\obsidian-vault
```

## Por que

La raiz `SGI` contiene codigo, dependencias, builds y archivos temporales. Si se abre como boveda, el grafo de Obsidian se mezcla con archivos que no son memoria del proyecto.

La carpeta `obsidian-vault` contiene solo la memoria del proyecto:

- notas
- decisiones
- pendientes
- assets
- bitacora
- grafo SGI
- configuracion de plugins

## En Obsidian

1. Selecciona `Open folder as vault`.
2. Elige la carpeta `obsidian-vault`.
3. Abre `Dashboard SGI`.
4. Abre `12-Grafo SGI/Indice Cerebro SGI`.
