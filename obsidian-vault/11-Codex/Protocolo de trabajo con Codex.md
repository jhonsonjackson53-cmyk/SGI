# Protocolo de trabajo con Codex

## Antes de cambiar codigo

1. Revisar `01-Proyecto SGI/Estado actual del proyecto SGI.md`.
2. Revisar pendientes relevantes.
3. Confirmar si hay decisiones previas que afecten el cambio.

## Durante el cambio

1. Mantener cambios acotados.
2. Validar TypeScript/build cuando aplique.
3. No tocar archivos temporales ni logs.

## Despues del cambio

1. Actualizar `07-Bitacora Codex/Bitacora de cambios.md`.
2. Actualizar pendientes si se agregan o completan tareas.
3. Registrar assets nuevos si hubo imagenes.
4. Commit y push a GitHub cuando el cambio este listo.
5. Confirmar deploy de GitHub Pages si afecta la web.

## Frase util para el usuario

"Actualiza la memoria Obsidian con lo que acabas de cambiar y subelo a GitHub."
