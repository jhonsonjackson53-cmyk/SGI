# Configuracion Graph View

#grafo #obsidian #configuracion

Esta nota explica como ver el grafo tipo cerebro en Obsidian.

## Paso rapido

1. Abrir `Graph view`.
2. Activar `Show tags` si quieres ver nodos por etiquetas.
3. Activar `Show attachments` solo si quieres ver archivos adjuntos.
4. Mantener `Show orphans` activado al inicio para ver notas sueltas.
5. Buscar `Indice Cerebro SGI` para centrar el grafo en el proyecto.

## Filtros utiles

Para ver solo la memoria SGI:

```text
path:obsidian-vault
```

Para ver solo servicios:

```text
path:13-Servicios
```

Para ver solo la web:

```text
path:14-Secciones Web
```

Para ver marcas, proveedores y sectores:

```text
path:17-Marcas y Tecnologias OR path:18-Proveedores OR path:19-Sectores
```

## Grupos de colores sugeridos

En Graph View, abre `Groups` y agrega:

| Grupo | Filtro | Color sugerido |
| --- | --- | --- |
| Herramientas | `path:12-Grafo SGI` | Azul |
| Servicios | `path:13-Servicios` | Rojo |
| Web | `path:14-Secciones Web` | Verde |
| Capacidades | `path:15-Capacidades Tecnicas` | Amarillo |
| Ingenieria | `path:16-Ingenieria y Suministros` | Cian |
| Marcas | `path:17-Marcas y Tecnologias` | Morado |
| Proveedores | `path:18-Proveedores` | Naranja |
| Sectores | `path:19-Sectores` | Rosa |
| Assets | `path:20-Assets Publicos` | Gris |
| Estrategia | `path:21-Estrategia` | Blanco |

## Ajustes visuales recomendados

- Node size: 1.1 a 1.4
- Link thickness: 0.8 a 1.2
- Repel force: 8 a 12
- Link force: 0.8 a 1.2
- Link distance: 180 a 260
- Text fade: bajo, para que se lean nombres.
