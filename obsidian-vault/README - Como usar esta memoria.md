# Memoria del proyecto SGI

Esta carpeta es la boveda de Obsidian para el proyecto SGI. Su funcion es guardar contexto, decisiones, pendientes, assets, textos y bitacora de cambios para que Codex, GitHub y Obsidian trabajen como un solo sistema.

## Flujo recomendado

1. Abrir `obsidian-vault` como boveda en Obsidian.
2. Guardar ideas rapidas en `00-Inbox`.
3. Mover decisiones confirmadas a `03-Decisiones`.
4. Mantener pendientes en `04-Pendientes/Pendientes.md`.
5. Registrar cada cambio importante en `07-Bitacora Codex/Bitacora de cambios.md`.
6. Subir cambios a GitHub junto con el codigo cuando haya avances relevantes.

## Roles

- Codex: ejecuta cambios, actualiza notas tecnicas y mantiene la bitacora.
- GitHub: versiona codigo, notas y despliegues.
- Obsidian: funciona como memoria del proyecto, planeacion y base de conocimiento.

## Reglas importantes

- No guardar contrasenas, tokens, llaves API ni datos privados sensibles.
- Cada decision importante debe tener fecha y motivo.
- Cada asset nuevo debe registrarse en `06-Assets e Imagenes/Assets pendientes.md`.
- Los textos definitivos del sitio deben vivir en `02-Contenido Web`.

## Plugins recomendados en Obsidian

- Obsidian Git: sincronizacion con GitHub.
- Templater: plantillas reutilizables.
- Dataview: listados automaticos de tareas, assets y decisiones.
- Tasks: gestion de pendientes.
- Canvas: mapa visual del sitio y flujo comercial.
